Put your picture files in this folder.

Then list them in content.js, like this:

  { src: "images/kitchen-before.jpg", caption: "Before", date: "2026" }

Tips
- Use .jpg for photographs, .png for screenshots.
- Keep files under about 1 MB each so the page loads fast. Exporting at
  around 2000 pixels on the long edge is plenty for a website.
- Lowercase filenames with dashes instead of spaces save a lot of headaches:
  "back-porch.jpg", not "Back Porch.JPG".
